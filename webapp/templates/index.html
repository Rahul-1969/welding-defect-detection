Model Datasheet

● DEPLOYED

RetinaNet is a one-stage object detection model that uses a Feature Pyramid Network (FPN) on top of a ResNet50 backbone. It applies focal loss to address class imbalance during training, enabling reliable detection of small and overlapping defect regions.

SYSTEM PIPELINE

How WeldAI Works

End-to-end inference flow from image upload to annotated result

01

IMAGE INPUT

User uploads a welding image via the inspection console.

02

PREPROCESSING

Image is resized to 640×640 and normalized to a float tensor.

03

RETINANET DETECTION

ResNet50 extracts features; RetinaNet predicts bounding boxes and defect classes.

04

VISUAL RESULT

Detections above threshold are drawn on the image and returned with telemetry.

About the Project

WeldAI is a computer vision system for automated welding quality inspection. A RetinaNet model with a ResNet50 backbone was trained to detect surface defects in welding seam images. The model outputs bounding boxes over detected defect regions along with per-detection confidence scores.
